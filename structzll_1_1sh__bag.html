Detailed Description

template<typename T, typename Acc = typename T::access>
struct zll::sh_bag< T, Acc >

Nodes of a skew heap held in no heap order, linked as a binary tree.

link and take cost O(1) amortized. Copying, moving or destroying a node in the bag changes its links as it would in a heap, and every other node stays in the bag. sh_heap::link( sh_bag&& ) puts the nodes in heap order.
